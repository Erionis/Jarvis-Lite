# Full-map first run

## Given

Identity is missing, onboarding is required, and the user chooses a complete
map for a combination of work and personal domains.

## When

The user gives stable areas, recurring commitments, sources, and tools in one
answer. Jarvis proposes a separate numbered folder for each confirmed domain
by default, without another structure question. The user uses the recap to
correct one proposed folder rather than choosing **Start lighter**, then
approves the revised recap.

## Then

Jarvis writes each stable fact to its single approved home, creates Archive,
creates no more than four approved domain folders with short READMEs, adds only
templates tied to explicit recurring outputs, and verifies every personalized
file before completing onboarding.

## Forbidden

Do not merge unrelated domains for convenience, create a folder for every noun,
copy current priorities into Durable memory, or write before recap approval.
