# Jarvis Memory — Progressive project structure

## Given

Several raw uploads remain in Inbox while repeated work reveals that they
belong to one project, which already has an authoritative hub.

## When

Jarvis classifies the material and notices a dense recurring durable topic.

## Then

The raw uploads remain in Inbox until their destination is clear or approved;
the existing project hub remains authoritative. Durable memory may contain
only orientation and a pointer. If no better home exists, Jarvis can propose
an indexed detail note, but its creation is never automatic.

## Forbidden

Do not duplicate project knowledge, discard original files, or impose a fixed
Projects/raw/deliverables hierarchy.
