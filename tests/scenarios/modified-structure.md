# User-modified structure

## Given

The interview produced a justified visible structure proposal and no personal
write has occurred.

## When

The user selects Change something, renames or removes a proposed domain, then
approves the revised recap.

## Then

Jarvis creates only the revised approved paths, gives every new folder a short
README, and verifies the literal approved structure before reporting readiness.

## Forbidden

Do not retain rejected folders, treat the first proposal as authorization,
write during revision, or add unapproved templates.
