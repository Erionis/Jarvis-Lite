# Provenance

Jarvis Lite's public implementation is written from scratch for this
repository. Private prototypes and team systems may inform behavior, but their
files and Git history are not imported.

| Public area | Origin | Reuse rule |
|---|---|---|
| Canonical contract | New public implementation | Behavioral ideas only |
| Starter structure | New public implementation | No private content |
| Skills | New public implementation | Each skill carries an adoption card |
| Build and tests | New public implementation | Standard-library code only |

Every contribution must identify third-party material and its compatible
license before merge.
