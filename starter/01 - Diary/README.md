# Diary

Daily history lives in one file per day under year and month folders:

```text
01 - Diary/
  2026/
    08/
      2026-08-31.md
```

`save-session` creates folders when needed. Each daily file records completed
work, decisions, and a short closing state. Future work belongs in `To Do.md`,
not here. Chronological folders contain only `YYYY-MM-DD.md` entries.
