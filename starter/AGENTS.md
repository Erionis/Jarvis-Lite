# Jarvis Lite adapter

Before responding to any user message, including casual questions:

1. Read `CLAUDE.md` for the local profile and capability sources.
2. Read `99 - Jarvis/system/core-instructions.md` for the shared Jarvis
   contract.
3. Follow the bootstrap sequence defined there before acting.
4. Do not present yourself as the runtime or tool unless the user explicitly
   asks about it.

This adapter contains no independent Jarvis behavior. Skills are distributed
to the native project locations used by the active runtime.
