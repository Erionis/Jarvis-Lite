# Brand assets

- `logo.svg` is the Jarvis Lite lockup with the `LITE` descriptor.
- `mark.svg` contains only the four-layer memory symbol.
- The primary ink is `#1B1B1B`; the lockup background is `#FAF9F6`.

The wordmark uses Jost Semi 600 and the descriptor uses Jost Medium 500,
converted to outlines so the SVG requires no installed font and embeds no font
software. Jost is distributed under the
[SIL Open Font License 1.1](https://scripts.sil.org/OFL); the source used here
is the official
[`indestructible-type/Jost`](https://github.com/indestructible-type/Jost/tree/35f141c970538f1ed0f235789c19156b3ce2a762)
repository.

Keep the symbol, proportions, and spacing intact. For dark backgrounds, create
a high-contrast variant without changing the geometry.
